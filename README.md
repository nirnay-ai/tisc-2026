# NirnayAI prototypes for TISC 2026

NirnayAI's entries for the Telangana Innovation Startup Challenge (TISC) 2026, Energy.

- Challenge 08, Network Mapping, Sectionalizing and Load Switching: **Feeder Planner** https://nirnay-ai.github.io/tisc-2026/08/ (demo film: https://nirnay-ai.github.io/tisc-2026/08/film/)
- Challenge 10, Solar Substation Potential Assessment: **Substation Solar Planner** https://nirnay-ai.github.io/tisc-2026/10/ (demo film: https://nirnay-ai.github.io/tisc-2026/10/film/)
- Challenge 16, DER and Rooftop-Solar Management: **Solar Headroom Desk** https://nirnay-ai.github.io/tisc-2026/16/ (demo film: https://nirnay-ai.github.io/tisc-2026/16/film/)
- Challenge 17, Storm / Weather Outage Prediction and Crew Dispatch: **Storm Desk** https://nirnay-ai.github.io/tisc-2026/17/ (demo film: https://nirnay-ai.github.io/tisc-2026/17/film/)

Each prototype is one file and runs offline in any browser. It uses public data, whose sources and notices are named inside each tool;
where a utility's own records are not public it uses a synthetic network and says so on the screen. Prototypes, not products in service.
